# dparsss's Discord Bot

A Discord bot I built as a personal project while learning JavaScript and Discord bot development.

This project was developed several years ago and is **no longer actively maintained**, but I’m keeping it as part of my development history and as an example of one of my earlier programming projects.

## Features

* Slash commands
* Moderation and admin commands
* Giveaway system
* AFK system
* Server statistics
* Utility commands
* Custom embeds
* MongoDB database integration
* Command cooldowns
* Event-based Discord interactions

## Technologies

* **JavaScript**
* **Node.js**
* **Discord.js**
* **MongoDB**
* **Mongoose**

## Project Structure
